# Support matrix

CodeWeaver only advertises language pairs that are implemented end to end:
parsing, IR mapping, code generation and target-toolchain validation.

| Source | Target | Status | Notes |
| ------ | ------ | ------ | ----- |
| Python 3.11+ | _none yet_ | in progress | Frontend and backend under construction. |

Anything not listed here is unsupported. Unsupported constructs are reported
explicitly rather than approximated.
