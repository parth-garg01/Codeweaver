      Execution policy

      • Type checking reads the generated files; it never runs them.
      • Running migrated tests executes generated code and is off unless the server was started with --allow-tests.
      • Installing dependencies needs the network and is off unless the server was started with --allow-install.

      Privacy

      • No LLM, no remote inference, no telemetry.
      • The UI listens on the loopback interface only and rejects requests addressed elsewhere.
      • Checkpoints store file hashes and counts, never source code.
